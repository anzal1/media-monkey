Rohan picks up one gold coin in an online match.
His balance suddenly displays 16,777,216 coins instead.
A missing conversion flipped the endianness byte order on the wire. 🪙

Endianness describes the sequence in which computer memory arranges individual bytes of a multi-byte word.

Here is where it bites:
→ A server sends a 32-bit packet payload over TCP
→ The client reads the raw network buffer directly into an integer struct
→ A single transferred health point turns into an instant maximum value overflow

Network protocols enforce big-endian ordering, sending the most significant byte first at the lowest memory address. The integer 1 travels across the wire as four sequential bytes: 0x00, 0x00, 0x00, 0x01.

Modern consumer processors, including x86 and standard Arm mobile chips, run in little-endian mode. They map the lowest memory address to the least significant byte. If the receiver skips byte swapping, the processor treats the first received byte (0x00) as the smallest place value and the trailing byte (0x01) as the 2^24 place value. That misplaced byte turns a single unit into exactly 16,777,216.

A single call to ntohl solves the entire problem by translating network byte order into the host's native layout.

Next time you parse raw network sockets, remember to swap before you cast.
