Big-O notation promised constant time inserts.
Your hardware benchmark shows the exact opposite.
Benchmarking arrays vs linked lists exposes why theory breaks.

Hardware hates pointer chasing because processors optimize for locality over instruction counts.

Picture this:
→ You allocate thousands of tiny list nodes on the heap
→ Every pointer jump triggers a cache miss to RAM
→ An array shifts thousands of bytes instantly in L1 cache

The CPU loads memory in fixed sixty-four byte chunks called cache lines. When elements sit sequentially in an array, loading the first brings the rest along for free. The hardware prefetcher recognizes the streaming pattern and pulls upcoming cache lines before the instructions execute.

A linked list scatters nodes across the heap. Each hop forces a full trip to system memory, stalling the execution pipeline for dozens of nanoseconds. Even though an array physically copies memory to insert, contiguous RAM moves so fast that arrays outperform lists on almost all practical workloads.
