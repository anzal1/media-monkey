Two's complement controls how your CPU handles signed arithmetic.
Positive numbers flip negative without a single warning.
Your absolute value function can return negative numbers. 💥

Two's complement is the binary encoding computers use to represent negative integers using simple addition hardware.

Here is where it bites:
→ Storing view counts in signed 32-bit fields
→ Running math.abs on the lowest possible signed integer
→ Assuming an overflow will safely wrap in optimized C

A 32-bit signed integer has an asymmetrical range. It stretches from negative 2,147,483,648 up to positive 2,147,483,647. Because zero claims a bit pattern where the leading sign bit is zero, positive numbers lose one slot.

When your counter hits INT_MAX and adds one, the CPU arithmetic logic unit carries that bit straight into the sign slot. The hardware treats the result as INT_MIN. If your code calls an absolute value function on that value, it flips the bits and adds one to invert it. But positive 2,147,483,648 does not exist in 32 bits, so it flips right back to negative.

In 2014, YouTube had to upgrade their view counter to a 64-bit integer because Psy's Gangnam Style broke past the 32-bit signed limit.
