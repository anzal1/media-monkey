Attention is the mathematical operation that allows modern transformers to connect every token to its context by computing pairwise relevance scores.

Here is where it bites:
→ A 2,048 token prompt builds a 4 million cell score matrix.
→ An 8,192 token prompt forces 67 million pairwise calculations.
→ High bandwidth memory stalls while transferring these massive intermediate grids.

Inside the transformer block, every token embedding turns into three vectors: query, key, and value. The query matrix multiplies directly against the transposed key matrix. This dot product produces an N by N attention score table representing how much each token needs every other token.

A softmax pass turns those raw numbers into probabilities, which weight the value vectors to produce the final context-aware output. The entire operation scales as O(N squared) in compute and un-tiled memory.

That quadratic scaling is why your H100s run out of VRAM the second someone drops an entire PDF into context without chunking.
