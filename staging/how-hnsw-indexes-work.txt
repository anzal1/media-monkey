Hierarchical Navigable Small World is a multi-layer graph index that enables logarithmic-time approximate nearest neighbor search across high-dimensional vector spaces.

Here is where it bites:
→ Running flat L2 or cosine scans over embeddings inside a user-facing loop
→ Hitting strict latency budgets when scaling a retrieval pipeline beyond one million chunks
→ Running out of instance RAM because graph edge pointers consume more memory than vectors

Search begins at the topmost layer of an HNSW graph. This sparse top layer contains long-range highway edges connecting distant vectors. Your query greedily hops across neighbors until it hits a local minimum, then drops vertically to the corresponding node in the denser layer below.

It repeats this process down through the hierarchy. By the time the search lands on layer zero, it is already centered in the exact semantic neighborhood, needing only a handful of local checks to collect the nearest k vectors.

Logarithmic search turns millions of floating-point distance checks into a few hundred hops, keeping p99 retrieval under five milliseconds.
