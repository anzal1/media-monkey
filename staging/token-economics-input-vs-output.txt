Token economics is the operational reality that generation costs dramatically more compute time and GPU memory than reading your prompt.

Here is where it bites:
→ An agent generates lengthy internal reasoning paragraphs before giving a two-word answer
→ A chat endpoint outputs markdown tables instead of compact serialized payloads
→ Your backend keeps batch sizes small because output context windows exhaust available GPU VRAM

When a model ingests your input prompt during prefill, it feeds all tokens simultaneously through the neural network. Thousands of tensor cores run matrix multiplications concurrently at maximum utilization.

Generation cannot work in parallel. The transformer must predict tokens one by one, reloading multi-gigabyte parameter weights over memory buses for every single prediction step. Each output token also expands the key-value cache, reserving active memory and blocking other requests from entering the execution batch.

Output tokens lock down hardware resources for hundreds of milliseconds, which is why API providers price outputs three to four times higher than inputs.
