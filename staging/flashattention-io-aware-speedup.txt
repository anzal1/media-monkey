FlashAttention is an exact attention algorithm designed around GPU memory hierarchy rather than raw floating-point operations.

Here is where it bites:
→ Sequence length squares the size of your attention matrix
→ Compute cores idle while reading millions of intermediate floats from HBM
→ Memory bus bandwidth chokes long before tensor cores saturate

Standard attention computes an N-by-N attention matrix, stores it completely in High Bandwidth Memory, and then reads it back into fast SRAM just to calculate softmax. That round-trip traffic across the memory bus wastes the majority of training time.

FlashAttention fixes this using tiling and online softmax. It streams small blocks of queries, keys, and values into local SRAM, calculates attention incrementally, and tracks running statistics to rescale outputs on the fly. It never materializes the full N-by-N matrix in main memory. During the backward pass, it actually recomputes the blocks on the fly because recomputing math inside cache is substantially faster than waiting on high bandwidth memory transfers.

On an NVIDIA A100, SRAM delivers roughly 19 TB/s of bandwidth compared to around 2 TB/s for HBM. Eliminating that memory traffic yields a 2x to 4x wall-clock speedup on exact attention.
