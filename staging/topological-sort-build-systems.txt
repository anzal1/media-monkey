A textbook topological sort was supposed to run cleanly. 💥

Topological sort is the algorithm that orders nodes in a directed graph so every dependency runs strictly before the step that needs it.

Picture this:
→ Core depends on nothing and compiles immediately
→ Auth depends on Core and waits in line
→ UI imports Auth and forms a dependency chain

Kahn algorithm tracks an in-degree counter for every node, representing the exact number of unfinished prerequisites. Leaf tasks with zero incoming dependencies enter the execution pool immediately. When a worker thread finishes compiling a task, it decrements the dependency counter for every downstream package attached to it.

Any node whose counter hits zero becomes immediately runnable. If packages import each other circularly, their counters can never hit zero, the work queue runs dry, and the scheduler detects an unresolvable cycle.

Flattening deep import pipelines into wide horizontal layers shrinks four-minute serial builds down to eighteen seconds across multi-core systems.

Remember this next time you design a monorepo architecture.
