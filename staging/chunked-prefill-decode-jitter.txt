Chunked prefill is an inference scheduling technique that slices large input prompts into uniform chunks so they run alongside decode steps.

Here is where it bites:
→ One user pastes a ten-page PDF for summarization.
→ The GPU devotes every tensor core to processing the prompt.
→ Five other active chats stop generating text for half a second.

LLM inference alternates between compute-bound prompt ingestion and memory-bandwidth-bound token generation. When an engine batches these together naively, a massive prompt prefill locks the tensor cores and stalls every running stream. That delay causes severe inter-token latency spikes.

By slicing the prompt into fixed chunks of 512 tokens, the scheduler mixes one slice of prefill compute with existing decode tokens in the same forward pass. You slightly increase time-to-first-token for the big prompt, but you eliminate the devastating p99 jitter on every other live user session.

You accept a slight hit to prompt processing to keep token streams perfectly uniform.
